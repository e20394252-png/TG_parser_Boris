🛡️ Безопасность

Умная защита от банов

Telegram отслеживает подозрительную активность. Задержка между сообщениями — ключевой параметр безопасности.

Аудитория Задержка Риск
Знакомые / друзья / коллеги 5–10 сек Низкий
Незнакомые пользователи 10–30 сек Средний
Большой список (100+ чел.) 30–60 сек Требует осторожности

⚠️ Система работает через живую Telegram-сессию (не бот), поэтому ведёт себя как обычный пользователь. Разумные задержки делают рассылку неотличимой от ручной.

⚙️ Технически

Как это работает

🔐

Личная Telegram-сессия

Используется ваша авторизованная MTProto-сессия через Telethon. Никаких API-ботов — сообщения приходят от вашего аккаунта.

🔄

Фоновая задача (BackgroundTasks)

Рассылка запускается асинхронно — интерфейс не блокируется, статус обновляется по polling каждые 4 секунды.

🗃️

PostgreSQL + изоляция по аккаунту

Каждый пользователь системы видит только свои рассылки. Результаты хранятся в таблицах broadcast_tasks и broadcast_results.

🔗

REST API с JWT-авторизацией

POST /broadcast/send, GET /broadcast/history, DELETE /broadcast/{id} — все эндпоинты защищены токеном.
